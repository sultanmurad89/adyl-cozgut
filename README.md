## 🚀 Пошаговая инструкция: Как залить сайт на GitHub Pages

Сайт полностью статический (чистый HTML5, CSS3, JavaScript) и не требует сборки.

### Вариант 1. Через браузер на GitHub.com (Самый простой)

1. Зайдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зеленую кнопку **«New»** (Создать новый репозиторий).
3. В поле **Repository name** укажите имя, например: `indaya-med`.
4. Сделайте репозиторий **Public** (публичным) и нажмите **«Create repository»**.
5. На открывшейся странице нажмите **«uploading an existing file»** (загрузить существующие файлы).
6. Перетащите в окно браузера все файлы и папки из папки `INDAYA`:
   - `index.html`
   - `css/`
   - `js/`
   - `assets/`
7. Нажмите **«Commit changes»**.
8. Перейдите во вкладку **Settings** (Настройки репозитория) ➔ слева раздел **Pages**.
9. В блоке **Build and deployment**:
   - В выпадающем списке **Branch** выберите `main` (или `master`) и папку `/ (root)`.
   - Нажмите **Save**.
10. Через 1–2 минуты обновите страницу — вверху появится зеленая плашка с готовой ссылкой:
    `https://ваш-логин.github.io/indaya-med/`

## 📲 Как подключить Telegram-бота для получения заявок

В файле `js/main.js` в самом верху находится блок конфигурации:

```javascript
const TELEGRAM_CONFIG = {
  ENABLED: true, // Поставьте true
  BOT_TOKEN: '123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ', // Токен от @BotFather
  CHAT_ID: '987654321' // Ваш ID от @userinfobot
};
```

1. Откройте в Telegram бота **@BotFather**, отправьте команду `/newbot`, укажите имя и получите `BOT_TOKEN`.
2. Напишите вашему созданному боту `/start` (чтобы разрешить ему слать вам сообщения).
3. Откройте бота **@userinfobot**, он покажет ваш персональный `Id` (это ваш `CHAT_ID`). Если хотите получать заявки в группу — добавьте бота в группу и укажите ID группы.
4. Вставьте значения в `js/main.js` и переключите `ENABLED: true`.
5. Теперь каждая заявка с сайта будет мгновенно приходить вам в Telegram с ФИО, телефоном, выбранным мессенджером, клиникой и описанием ситуации!

## 📞 Как изменить контактный номер WhatsApp / телефона

В файле `js/main.js` измените строку:
```javascript
const WHATSAPP_NUMBER = '99365677550'; // Ваш номер без плюса (например 99365123456)
```
И в `index.html` найдите номер `+993 (65) 67-75-50` и замените на ваш реальный номер.
